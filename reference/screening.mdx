Screening runs before the interview. Each question lists the `acceptable_options` that qualify a participant. Participants who don't qualify see the disqualification message and can be redirected.

```python
client.screening.create_question(
    study.id,
    question="Do you use the product at work?",
    options=["Yes", "No"],
    acceptable_options=["Yes"],
)
client.screening.set_settings(study.id, enabled=True, disqualification_message="Thanks anyway!")
```

## get()

```python
client.screening.get(study_id) -> ScreeningOut
```

Screening settings plus the ordered question list.

**Returns** [`ScreeningOut`](/reference/models#screeningout).

## set_settings()

```python
client.screening.set_settings(
    study_id, *, enabled: bool, disqualification_message: str | None = None, redirect_url: str | None = None
) -> ScreeningSettingsOut
```

Enable or disable screening. Disabling keeps the questions and settings.

<ParamField body="enabled" type="bool" required>
  Whether screening runs before the interview.
</ParamField>

<ParamField body="disqualification_message" type="str">
  Shown to participants who don't qualify.
</ParamField>

<ParamField body="redirect_url" type="str">
  Where disqualified participants are sent. May contain `{{external_participant_id}}`.
</ParamField>

**Returns** [`ScreeningSettingsOut`](/reference/models#screeningsettingsout).

## create_question()

```python
client.screening.create_question(
    study_id, *, question: str, options: list[str], acceptable_options: list[str]
```

<ParamField body="question" type="str" required>
  Question text.
</ParamField>

<ParamField body="options" type="list[str]" required>
  Answer options.
</ParamField>

<ParamField body="acceptable_options" type="list[str]" required>
  The subset of `options` that qualify the participant.
</ParamField>

**Returns** [`ScreeningQuestionOut`](/reference/models#screeningquestionout).
